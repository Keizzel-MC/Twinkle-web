Herramientas del proyecto
Menos vueltas.
Más organización.
El proyecto reúne utilidades de administración. Las funciones concretas pueden variar según la versión Web o Desktop, el sistema y el tipo de servidor.
⌘
Consola del servidor
Accede a la salida de la consola y a los controles disponibles en tu instalación.
▤
Gestión de archivos
Explora y administra archivos de configuración y carpetas del servidor desde el panel.
✦
Mods e instaladores
Consulta las herramientas de instalación compatibles con tu versión y cargador.
◫
Servidores organizados
Administra las configuraciones y servidores disponibles en tu entorno.
◇
Java y memoria
El proyecto contempla opciones de configuración del entorno de ejecución, según edición.

Conoce Twinkle
Una herramienta para quienes construyen sus propios mundos.
Twinkle surge como una iniciativa independiente para simplificar tareas habituales de administración de servidores de Minecraft. No es un servicio oficial de Mojang ni una plataforma de alojamiento de servidores.
